## 2. Mathematical Profitability & "Will We Be in Loss?" Analysis

### 🎯 **Direct Verdict: NO, YOU WILL NOT BE IN A LOSS.**

Across all 267 dishes at Anand Stall and all campus canteens, **every single item generates a guaranteed net positive profit** between **₹2.40 and ₹7.67** after paying the 2.5% Payment Gateway fee.

### 📐 Break-Even Point Calculation (Tier 4: +₹13 Hike)
For a flat hike of **₹13** to equal the 2.5% PG transaction fee:
$$\text{PG Fee} = P_{\text{final}} \times 0.025 = 13$$
$$P_{\text{final}} = \frac{13}{0.025} = ₹520$$
$$P_{\text{base}} = 520 - 13 = \mathbf{₹507}$$

- **Break-Even Threshold**: A single item would have to cost **more than ₹507** for the 2.5% PG cut to exceed the ₹13 flat hike.
- **Current Highest Dish**: The most expensive item in Anand Stall is the **Anand Sp. Matka Dosa at ₹340**.
  - Final price: ₹340 + ₹13 = **₹353**
  - 2.5% PG cut: ₹353 × 0.025 = **₹8.83**
  - Vendor payout: **₹340.00** (100% protected)
  - **Net Platform Profit: ₹13.00 - ₹8.83 = +₹4.17** *(Profitable!)*

## 4. Cart Level Compounding (Why Multi-Item Orders Are Even More Profitable)

When a student orders multiple items in one checkout:
- **Example Cart**:
  - 1 × Butter Vada Pav (Base ₹30 + ₹4 = ₹34)
  - 1 × Classic Cold Coffee (Base ₹100 + ₹10 = ₹110)
  - 1 × Sp. Jinny Dosa (Base ₹220 + ₹13 = ₹233)
- **Total Customer Bill**: ₹34 + ₹110 + ₹233 = **₹377**
- **Total Platform Flat Markup Collected**: ₹4 + ₹10 + ₹13 = **₹27.00**
- **Total 2.5% PG Cut**: ₹377 × 0.025 = **₹9.43**
- **Total Vendor Payout**: ₹30 + ₹100 + ₹220 = **₹350.00** (100% intact)
- **CampusBites Net Profit on this Order**: ₹27.00 - ₹9.43 = **+₹17.57** (a massive **65% retention** of collected fees).

## 5. Technical Blueprint (For Future Code Integration)

```typescript
/**
 * Revamped Tiered Flat-Fee Calculator
 * Rule:
 *   ₹1   - ₹49  => +₹4
 *   ₹50  - ₹99  => +₹5
 *   ₹100 - ₹199 => +₹10
 *   ₹200+       => +₹13
 */
export function calculateRevampedPrice(basePrice: number) {
  let hike = 4;
  if (basePrice < 50) {
    hike = 4;
  } else if (basePrice < 100) {
    hike = 5;
  } else if (basePrice < 200) {
    hike = 10;
  } else {
    hike = 13;
  }

  const finalPrice = basePrice + hike;
  const pgCut = Math.round((finalPrice * 0.025) * 100) / 100;
  const netProfit = Math.round((hike - pgCut) * 100) / 100;

  return {
    basePrice,
    hike,
    finalPrice,
    pgCut,
    vendorPayout: basePrice,
    netProfit,
  };
}
```
